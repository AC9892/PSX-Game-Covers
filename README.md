# PSX Game Covers

A collection of flat front-cover artwork for PlayStation games, organized for use with **PSX Disc File Compressor** and other personal game-library tools.

The images in this collection are sourced from existing community artwork projects. I did not create the original game artwork.

| Platform | Source | Original collection |
| --- | --- | --- |

Please visit the original projects for their full credits.

## Image format

This collection is intended to contain **flat front covers only**, not 3D box renders. Images may be resized or converted to **WebP** to reduce storage requirements. Conversion does not transfer ownership of the original artwork.
